# Open Sans

`OpenSans.ttf` is the unmodified Open Sans variable font from Google Fonts
(`OpenSans[wdth,wght].ttf`, normal style, weights 300–800).

Source: https://github.com/google/fonts/tree/main/ofl/opensans
Upstream font: https://raw.githubusercontent.com/google/fonts/main/ofl/opensans/OpenSans%5Bwdth%2Cwght%5D.ttf

Copyright 2020 The Open Sans Project Authors (https://github.com/googlefonts/opensans).
The font is distributed under the SIL Open Font License 1.1, included in
`OpenSans.OFL.txt`. It has its own license, separate from the application's MIT license.

The report embeds the font as a data URL and includes the license as a CSS comment.
Opening the HTML never downloads fonts. Retain the font and its license together.
